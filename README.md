# 数理星图 · 学习激励站

一个深黑科技风的**学习激励网站**，把「数学技能树」「物理技能树」「名次攀登天梯」整合到一个站点，顶部页签一键切换：

| 页签 | 功能 |
|---|---|
| 🧮 **数学星图** | 初中数学技能树：按教材顺序（七上→九下）横向卷轴，点击点亮技能 |
| ⚛️ **物理星图** | 初中物理技能树：按教材顺序（八上→九下）横向卷轴，点击点亮技能 |
| 🏆 **名次天梯** | 学习名次攀登系统：黑色高耸的名次高山（4000px），纵向拖动浏览，录入考试名次自动结算奖励 |

## 🏆 名次天梯奖励规则

- 🎯 **首次突破前 100 名**：一次性奖励 **¥300**
- 🚀 **此后每进步一名都有奖励**（按名次区间）：

| 区间 | 每名奖励 | 区间累计 |
|---|---|---|
| 前 100 → 前 80 | ¥20 | ¥400 |
| 前 80 → 前 60 | ¥25 | ¥500 |
| 前 60 → 前 40 | ¥35 | ¥700 |
| 前 40 → 前 30 | ¥100 | ¥1,000 |
| 前 30 → 前 20 | ¥140 | ¥1,400 |
| 前 20 → 前 10 | ¥200 | ¥2,000 |
| 前 10 → 第 1 | ≈¥333.33 | ¥3,000 |

> 全程登顶累计 = 300 + 400 + 500 + 700 + 1000 + 1400 + 2000 + 3000 = **¥9,300**。
> 跨区间进步时按每步所在区间分别计费，自动结算。

## ✨ 天梯功能

- 🏔 **高耸黑色名山**：名次第 1 名在山顶、第 100 名在山脚，山体 4000px 高，需纵向拖动 / 滚轮 / 触摸滑动浏览，顶栏实时显示「当前海拔」
- 📝 **考试记录**：录入考试名称 / 日期 / 科目 / 名次 / 总人数，自动排序结算
- 🪧 **营地路牌**：7 个奖励区间在山体上呈「登山营地」指示牌（青→紫→金），显示区间累计奖励、每名奖励与已领进度
- 📈 **登山轨迹**：历次考试名次以科目色发光圆点标记在山脊上，虚线轨迹连接爬升路径，金色「★历史最佳」徽章
- 💰 **奖励结算**：每次考试的进步名次、获得奖励、首次突破前 100 标记自动计算并展示
- ✅ **已领取状态**：到达过的名次/区间显示"已领取"进度，未到达显示未解锁
- 💾 数据保存在浏览器 localStorage

## 📁 文件结构

```
star-site/
├── index.html       # 站点壳：导航 + 三视图容器
├── styles.css       # 全部样式（背景 / 树 / 天梯）
├── data-math.js     # 数学技能树数据（MATH_TREE）
├── data-physics.js  # 物理技能树数据（PHYSICS_TREE）
├── app-tree.js      # 通用技能树渲染器（数学/物理共用）
├── app-ladder.js    # 名次天梯（奖励算法 / 天梯 UI / 记录管理）
├── app.js           # 入口：页签路由 / 共享粒子背景
├── server.js        # 零依赖本地预览服务器
└── README.md
```

## ▶️ 本地预览

```bash
node server.js            # 打开 http://localhost:4175
# 或 PORT=4176 node server.js 换端口
```

## 🚀 部署上线（任选其一）

纯静态页面，无需构建。

### 1. GitHub Pages

```bash
cd star-site
git init && git add . && git commit -m "init: 学习激励站"
git branch -M main
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```
仓库 Settings → Pages → 选择 `main` 分支 / root 即可。

### 2. Vercel / Netlify / Cloudflare Pages

- Vercel：`npx vercel` 或导入仓库（Framework Preset 选 **Other**）
- Netlify：把 `star-site` 文件夹拖到 [app.netlify.com/drop](https://app.netlify.com/drop)
- Cloudflare Pages：连接仓库或上传目录（构建命令留空）

## 💡 使用提示

- 三个页面的数据（技能点亮、天梯记录）分别保存在浏览器 localStorage
- 修改 `data-math.js` / `data-physics.js` 可增删知识点；天梯奖励规则在 `app-ladder.js` 顶部的 `REWARD` 常量中调整
